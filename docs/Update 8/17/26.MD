# Project Update - August 17, 2026

## Security Hub Account Management

- Added a dedicated revoked-account state using the nullable `users.revoked_at` timestamp.
- Separated staff accounts into three distinct lists:
  - Pending accounts are registered staff awaiting their first approval.
  - Active accounts are approved staff with system access.
  - Revoked accounts are previously active staff whose access was removed.
- Consolidated the three account lists into a single **Account Management** card with Pending, Active, and Revoked tabs.
- Added count badges to each account tab.
- Replaced inline account buttons with ellipsis action dropdowns:
  - Pending: Approve or Decline.
  - Active: Revoke Access.
  - Revoked: Restore Access or Delete Account.
- Action dropdowns close when another tab is selected or the user clicks elsewhere.

## Revoked Account Workflow

- Revoking an active staff account now sets `is_approved` to `false` and records `revoked_at`.
- Revoked accounts no longer return to Pending Approvals.
- Restoring access sets `is_approved` to `true` and clears `revoked_at`.
- Revoked accounts can be permanently deleted from their action dropdown.
- Restore and delete endpoints reject pending, active, and administrator accounts.
- Audit-log entries and success messages were added for revoke, restore, and permanent deletion actions.
- Existing unapproved accounts remain classified as pending after migration.

## Authentication Feedback

- Pending users continue to receive the awaiting-administrator-approval message.
- Revoked users now receive a separate message stating that an administrator revoked their access.
- Active sessions are still terminated when access is revoked.

## Confirmation and Form Behavior

- Replaced the browser-native Revoke Access confirmation dialog with a styled in-page confirmation card.
- The card displays the selected staff member and the consequences of revocation.
- It can be dismissed through Cancel, the close button, backdrop click, or the Escape key.
- Cancelled form confirmations no longer leave submit buttons in the animated Processing state.

## Sales Interface

- Removed the clear "x" from the selected **Select Item from Inventory** dropdown while retaining searchable Select2 behavior.
